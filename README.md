# Erisson Barbeiro | Minisite

Minisite da barbearia **Erisson Barbeiro** (Orobó-PE). Página estática em HTML e CSS, sem dependências nem build.

- Instagram: https://www.instagram.com/_erisson_barbeiro/
- WhatsApp: https://w.app/5idc2r
- Horário: segunda a sábado, das 8h às 18h

## Estrutura

```
index.html
css/style.css
assets/img/   logo, foto do topo e galeria
```

## Como ver no computador

Abra o `index.html` no navegador.

## Publicar no GitHub Pages

1. Envie os arquivos para um repositório.
2. Vá em **Settings > Pages**.
3. Em **Source**, escolha **Deploy from a branch**, branch `main` e pasta `/ (root)`.
4. O site fica em `https://SEU-USUARIO.github.io/NOME-DO-REPOSITORIO/`.

## Como editar

- Textos, links e telefone: `index.html`
- Cores e tamanhos: `css/style.css` (a cor dourada está em `--gold`)
- Fotos: substitua os arquivos em `assets/img/` mantendo os mesmos nomes
